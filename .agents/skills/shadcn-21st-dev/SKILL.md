# 21st.dev Component Skill

This skill provides access to premium shadcn/ui components from 21st.dev.
It guides the agent to use modern, polished components for tables, badges, and grids.

## Components
- **Card Grid**: Use for displaying items in a responsive grid.
- **Modern Badge**: Use for status indicators with semantic colors.
- **Interactive Table**: Use for data management with CRUD operations.
